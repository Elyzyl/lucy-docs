## Local preview

Open `index.html` in any browser — no build step required, it's pure static HTML.

## Stack

- Pure HTML + CSS, no frameworks
- [Mermaid](https://mermaid.js.org/) via CDN for architecture diagrams
- [IBM Plex Sans + Mono](https://www.ibm.com/plex/) via Google Fonts
- Hosted on GitHub Pages
