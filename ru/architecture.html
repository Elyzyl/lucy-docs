Архитектура (обзор)

Lucy использует двухмодельную архитектуру: быстрая Junior Model для лёгких реакций и глубокая Senior Model для нюансного рассуждения. Переключение между ними — на блюпринте обозначено как ESCALATE / RETURN — её внутреннее решение.

Полная схема

Две модели

Junior Model — быстрый вывод

  • Средняя задержка ≈ 0.9–1.2 с
  • Лёгкие реплики: болтовня, команды, шутки, междометия
  • Обрабатывает большую часть рутинных ходов

Senior Model — глубокое рассуждение

  • Средняя задержка ≈ 3–6 с
  • Сложные запросы, код, нюансы, эмоциональный контекст
  • Активируется через эскалацию (Junior решает сам, либо явная просьба)
  • Возвращает ход Junior'у когда сложность разговора спадает

Переход между ними — её внутреннее решение, заметен как чуть более длинная пауза перед ответом.

Layer 1 — Interface

  • Discord Gateway — входящие текстовые сообщения, упоминания, реплаи
  • Voice Gateway — входящий аудиопоток из голосового канала
  • Owner DM Channel — приватный канал управления к хосту

Layer 2 — Input Processing

  • STT Module — распознавание речи Whisper-класса, задержка ≈150 мс
  • VAD — детектор активности, сегментирует реплики
  • Wake Word Filter — ключевое слово для активации голосом
  • Message Classifier — шанс ответа, детект упоминаний, grace-mode логика

Layer 3 — Core / Cognition

  • Router — центральный диспатчер, решает какая модель ведёт ход
  • Context Snapshot — состояние хода: кто, где, когда, recent events, активная модель
  • Persona Builder — собирает системный промпт из модульных шаблонов
  • Identity Firewall — pre-фильтр и post-фильтр для защиты от identity-leak
  • Junior Model + Senior Model (выше) с control flow ESCALATE / RETURN

Layer 4 — Execution / Output

  • Tool Registry — function-calling диспатч (~20 инструментов)
  • TTS Module — стриминговый синтез речи
  • Music Player — аудиопоток в голосовой канал
  • Message Composer — финальная сборка ответа, удаление action-tag'ов
  • Escalation Dispatch — алерты в ЛС хоста на ручную обработку
